프로세스 정보:
| 프로세스 | 도착시각 | CPU 사이클 |
|---------|---------|------------|
| 가      | 1       | 4          |
| 나      | 2       | 3          |
| 다      | 3       | 1          |

## SJF (Shortest Job First)
* **비선점형** 스케줄링: 실행 중인 프로세스는 완료될 때까지 CPU 점유
* 대기 중인 프로세스 중 CPU 사이클이 가장 짧은 프로세스에 CPU 할당

### 실행 순서:
1. 시각 1: 프로세스 '가' 도착 및 실행 시작 (유일한 프로세스)
2. 시각 2: 프로세스 '나' 도착 (대기 상태, '가'가 실행 중)
3. 시각 3: 프로세스 '다' 도착 (대기 상태, '가'가 실행 중)
4. 시각 5: 프로세스 '가' 종료, 대기 중인 '다'와 '나' 중 '다'가 CPU 사이클이 더 짧으므로 '다' 실행 시작
5. 시각 6: 프로세스 '다' 종료, 남은 '나' 실행 시작
6. 시각 9: 프로세스 '나' 종료, 모든 프로세스 완료

## SRT (Shortest Remaining Time)
* **선점형** 스케줄링: 남은 실행 시간이 더 짧은 프로세스가 도착하면 현재 실행 중인 프로세스를 중단하고 CPU 할당

### 실행 순서:
1. 시각 1: 프로세스 '가' 도착 및 실행 시작 (남은 시간: 4)
2. 시각 2: 프로세스 '나' 도착 (남은 시간: 3), '가'의 남은 시간은 3
   * 둘의 남은 시간이 같으므로 먼저 실행 중이던 '가' 계속 실행 (타이브레이크 규칙)
3. 시각 3: 프로세스 '다' 도착 (남은 시간: 1), '가'의 남은 시간은 2
   * '다'의 남은 시간이 더 짧으므로 '가' 중단, '다' 실행 시작
4. 시각 4: 프로세스 '다' 종료, '가'와 '나' 중 '가'의 남은 시간(2)이 더 짧으므로 '가' 실행 재개
5. 시각 6: 프로세스 '가' 종료, 남은 '나'(남은 시간: 3) 실행 시작
6. 시각 9: 프로세스 '나' 종료, 모든 프로세스 완료
