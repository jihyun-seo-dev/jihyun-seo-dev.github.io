# 카카오 로그인 스터디

**참고 블로그**

> 📎 [https://ddonghyeo.tistory.com/16](https://ddonghyeo.tistory.com/16)

## 카카오 로그인을 구현하기 위한 전체적인 로직

1. **인가 코드 발급**:
   - 사용자가 카카오 로그인을 통해 애플리케이션에 접근할 수 있도록 인가 코드를 요청 및 발급
2. **인가 코드로 액세스 토큰 발급**:
   - 인가 코드(Authorization Code)를 사용하여 카카오 서버에서 액세스 토큰(Access Token)을 발급
3. **액세스 토큰으로 사용자 정보 조회**:
   - 발급받은 액세스 토큰을 이용하여 카카오 서버에서 사용자 정보를 조회

## 2단계: 인가 코드 요청

- URL: `https://kauth.kakao.com/oauth/authorize?client_id={REST_API_KEY}&redirect_uri={REDIRECT_URI}&response_type=code`

![인가 코드 요청 1](/assets/images/2025-04-30-11.png)

![인가 코드 요청 2](/assets/images/2025-04-30-12.png)

## 3단계: 인가 코드를 사용하여 액세스 토큰 요청

- **POST** `https://kauth.kakao.com/oauth/token`

![액세스 토큰 요청](/assets/images/2025-04-30-13.png)

## 4단계: 액세스 토큰으로 사용자 정보 가져오기

1. **GET** `https://kapi.kakao.com/v2/user/me`
2. **Headers**에 위에서 발급 받은 **access_token** 입력

![사용자 정보 요청](/assets/images/2025-04-30-14.png)
